# 💬 Support

Need help with Fluxlane?

## 🧭 Start Here

1. Read the [README](../README.md).
2. Check your Node.js and npm versions.
3. Run `npm install` again if dependencies look broken.
4. Run `npm run typecheck` to catch local setup issues.

## 🐛 Bugs

Open an issue:

https://github.com/RensithUdara/Fluxlane-Application/issues

Include:

- macOS version.
- Node.js version.
- npm version.
- What you tried.
- What happened.
- Any terminal output.

## 💡 Feature Requests

Open a GitHub issue with the feature idea and why it would help.
