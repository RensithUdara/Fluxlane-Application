# 🤝 Contributing to Fluxlane

Thanks for helping improve Fluxlane.

## 🚀 Quick Start

```bash
git clone https://github.com/RensithUdara/Fluxlane-Application.git
cd Fluxlane-Application
npm install
npm run dev
```

## ✅ Before You Submit

Please run:

```bash
npm run typecheck
npm run lint
```

Format changed files if needed:

```bash
npm run format
```

## 🧩 Good First Contributions

- Fix UI polish issues.
- Improve README or docs.
- Add tests for download helpers.
- Improve error messages.
- Improve platform-specific setup notes.

## 🛠️ Pull Request Guidelines

- Keep changes focused.
- Explain what changed and why.
- Include screenshots for UI changes.
- Mention any known limitations.
- Do not mix unrelated refactors with feature work.

## 🐛 Reporting Bugs

Please include:

- Your macOS version.
- Node.js and npm versions.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Console output or screenshots if useful.

## 💡 Feature Requests

Open an issue with:

- The problem you want to solve.
- Your proposed behavior.
- Any UI or workflow examples.

## 📜 Code of Conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
